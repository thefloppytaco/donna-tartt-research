How to read this site. Tier A is work by Tartt — the editions, essays, contributions and interviews. Tier B is material about her, kept separate on purpose. Quotations inside a transcript or an excerpt are Tartt's; descriptive prose in the reference is the compiler's. Claims are cross-checked against primary sources where possible, and anything single-sourced or unsettled is logged in the verification report.

Asking an AI instead of reading? The repository ships an AGENTS.md that tells an assistant how to search this corpus and answer with citations rather than from memory.
